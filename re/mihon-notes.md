## 3. Extension / repo ("store") model

- Mihon 0.21 renames repos to "extension stores": domain model `mihon.domain.extension.model.ExtensionStore { name, indexUrl, extensionListUrl, signingKey, contact: Contact{website, discord}, isLegacy, badgeLabel }`; interactors `AddExtensionStore`, `GetExtensionStores`, `RemoveExtensionStore`, `UpdateExtensionStores`, `GetExtensionStoreCountAsFlow`; repo `ExtensionStoreRepositoryImpl` (DB table), UI `ExtensionStoresViewModel`.
- Adding: user pastes a "Store index URL" (`extensionStoresScreen_addStoreInput_inputLabel`) or opens a deeplink. `mihon.data.extension.service.ExtensionStoreService.fetchStore` fetches it (gzip-aware `decompressIfGzipped`, protobuf via `kotlinx.serialization.protobuf`, JSON fallback). Literals in the method: `/index.min.json`, `/repo.json`, `"Provided legacy store url is not valid"` and `NetworkLegacyExtensionRepo.getIndexV2()`: a URL ending in `/index.min.json` is treated as a legacy Tachiyomi/Keiyoushi repo (`isLegacy=true`, store derived from `repo.json`), otherwise the URL is a new-format store index (`NetworkExtensionStore { name, extensionListUrl, signingKey, contact, extensionList, badgeLabel }` with nested `Extension`, `Source`, `Resources`, `ContentWarning`). The extension list itself is fetched from `extensionListUrl` (`getExtensions`). Dex literals also include `/index.json`, `/icon/`, `.apk`. Duplicate -> `extensionStoresScreen_addStore_alreadyExists`. (No `index.pb` literal found in this build.)
- Extension model `eu.kanade.tachiyomi.extension.model.Extension`: `Available { pkgName, name, versionName, versionCode, libVersion, lang, contentWarning, sources, apkUrl, iconUrl, store }`, `Installed { hasUpdate, signatures, store, isShared, findUpdate(), findListing() }` (store null => orphaned: `ext_obsolete` "Orphaned", `obsolete_extension_message`), `NotLoaded` / `Loaded` (`ext_not_loaded`, reasons `ext_unsigned_message`, `ext_unsupported_message`, `ext_malformed_message`, `ext_load_failed_message`, `ext_filtered_message`). Untrusted: signature not matching store `signingKey` -> `ext_untrusted` with dialog `untrusted_extension_message`, actions `ext_trust`, `ext_revoke_trust`.
- Install flow `InstallStep`: Idle, Pending (`ext_pending`), Downloading (`ext_downloading`), Installing (`ext_installing`), Installed, Error. Installer choice (`ext_installer_pref`): Legacy, PackageInstaller, Shizuku, Private (`extension.installer.PackageInstallerInstaller`, `ShizukuInstaller`; `ExtensionInstaller.downloadAndInstall`). Updates: `ExtensionUpdateNotifier`, `ext_update`, `ext_update_all`; uninstall `ext_uninstall` / `ext_remove`.
- Content warning / NSFW: enum `mihon.domain.extension.model.ContentWarning { SAFE, MIXED, NSFW }` (`ext_content_warning_safe|mixed|nsfw`, descriptions `_description`); settings `pref_apply_content_warnings_to_installed` (also hide already-installed), label `ContentWarningLabel`. This replaces the old boolean NSFW toggle.
- Language filter: `ExtensionFilterViewModel` / `ExtensionFilterState` (enabled languages set), `SourcesFilterViewModel` for sources; `multi_lang`, `other_source`, `ext_info_language`. Extension list grouped by language headers.

## 6. Backup format

- Protobuf (`kotlinx.serialization.protobuf`, `@ProtoNumber` fields), gzip-compressed; file `app.mihon_YYYY-MM-DD_HH-mm.tachibk` (regex literal in dex), MIME `application/x-protobuf+gzip`; JSON backups rejected (`invalid_backup_file_json`). Classes `data.backup.BackupCreator/BackupRestorer`, `BackupWriter/BackupReader/BackupDecoder`, `BackupFileValidator`.
- Root `models.Backup { backupManga[], backupCategories[], backupSources[], backupPreferences[], backupSourcePreferences[], backupExtensionStores[] }`.
- `BackupManga { source, url, title, artist, author, description, genre[], status, thumbnailUrl, dateAdded, viewer, viewer_flags, chapters[], categories[], tracking[], favorite, chapterFlags, history[], updateStrategy, excludedScanlators[], notes, favoriteModifiedAt, nextUpdate, initialized, memo }`; `BackupChapter { url, name, scanlator, read, bookmark, lastPageRead, dateFetch, dateUpload, chapterNumber, sourceOrder, memo }`; `BackupTracking { syncId, libraryId, mediaId, trackingUrl, title, lastChapterRead, totalChapters, score, status, startedReadingDate, finishedReadingDate, private }`; `BackupHistory`, `BackupCategory`, `BackupSource`, `BackupExtensionStore`, `BackupPreference` with typed values (`Int|Long|Float|String|Boolean|StringSet PreferenceValue`).
- Options: `BackupOptions { libraryEntries, categories, chapters, tracking, history, appSettings, extensionStores, sourceSettings, privateSettings, readEntries }`; `RestoreOptions { libraryEntries, categories, appSettings, extensionStores, sourceSettings }`; automatic backups `pref_backup_interval`, `last_auto_backup_info`.
